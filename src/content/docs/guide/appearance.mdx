With iCloud Sync on, your palette, and so your icon, is the same on all your devices. iOS only changes an app's icon while it's open, so the icon updates next time you open Honya on each one.

## Columns

**Columns** sets how many covers fit across the screen, everywhere: the library, Browse, seasons, search results and Discover. **Auto** fits as many as the screen's width allows, keeping covers the same size as you rotate or resize. The column count is set on each device.

The library's own layout, compact grid, comfortable grid or covers only, is in the library's **Options**. See [Your library](/guide/library/#sort-filter-and-display).
